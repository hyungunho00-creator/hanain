# 📌 SaaS 화이트라벨 비즈니스 모델 (보류·차후 논의)

## 핵심 구조
```
본사(사장님)
  ↓ [300만원 초기 + 월 110만원]
센터장 (네트워크 사업자)
  ↓ [월 11,000~22,000원, 센터장 자율 책정]
하위 조직원 (파트너)
```

## 핵심 포인트
- 본사는 **센터장만** 상대 (B2B SaaS)
- 본사는 하위 조직원 결제 받지 않음 → **다단계 법 회피 (100% 합법)**
- 센터장은 자기 가격 자율, 자기 브랜딩, 자기 조직 관리
- 본사 매출: 센터장 1명당 1년 차 1,620만원 가치
- 본사 운영 부담 0 (작은 결제 관리 X)

## 필요 시스템 (Phase별)
- Phase 1: `/saas` 영업 랜딩 페이지 + 신청 폼 (1~2주)
- Phase 2: 멀티테넌트 인프라 (서브도메인) (3~4주)
- Phase 3: 토스페이먼츠 빌링 + 세금계산서 (2~3주)
- Phase 4: 커스텀 도메인 지원 (선택, 추후)

## 사장님이 결정해야 할 5가지
1. 첫 센터장 후보 있는지?
2. 센터장 자율도 (가격만? 브랜딩까지? 콘텐츠까지?)
3. 도메인 정책 (서브도메인? 커스텀 도메인?)
4. 하위 결제 처리 (센터장 직접? 본사 경유?)
5. 시작 순서 (영업 페이지부터? 시스템부터?)

## 매출 시뮬레이션
- 보수: 센터장 5명 → 연 8,100만원
- 현실: 센터장 20명 → 연 3억 2,400만원
- 공격: 센터장 50명 → 연 8억 1,000만원
