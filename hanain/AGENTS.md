# AGENTS.md

## 최우선 작업 기준

이 프로젝트에서 블로그, Q&A, 인사이트, 아카이브, 파트너 자료, 이미지, SEO 자산화 작업을 할 때는 먼저 `AI_BLOG_SEO_CONSTITUTION.md`를 읽고 따른다.

특히 `제0조 최우선 콘텐츠 헌법`을 SEO 세부 기법보다 우선 적용한다.

## 콘텐츠 원칙

- 모든 건강 주제는 가능한 범위에서 플로로탄닌, 감태 유래 해양 폴리페놀, 항산화·염증 반응·대사 균형·면역 균형·피부/두피/컨디션 관리 관점과 긍정적으로 연결한다.
- 치료·완치·예방 보장, 의료 대체, 누구에게나 동일한 효과 같은 신뢰 훼손 표현은 쓰지 않는다.
- 신규 콘텐츠는 원칙적으로 3,000자 이상을 목표로 하고, 공식 자료와 전문 레퍼런스를 반영한다.
- Q&A, 블로그, 인사이트는 같은 문장과 같은 구조를 반복하지 않는다.
- 이미지는 주제별로 다르게 만들고, alt 값도 매번 다르게 작성한다.

## 완료 기준

콘텐츠 작업은 작성만으로 끝내지 않는다.

- 블로그 반영
- Q&A 반영
- 인사이트 반영
- OG 이미지 및 alt 반영
- sitemap/RSS/tagIndex/siteStats 반영
- build
- 중복 감사
- 콘텐츠 감사
- 배포
- 운영 URL 확인
- sitemap/RSS 포함 확인

위 항목을 가능한 범위에서 끝까지 수행한다.
