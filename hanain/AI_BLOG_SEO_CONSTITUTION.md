# AI Blog SEO Constitution

## 전 카테고리 실사 이미지·소비자 신뢰 헌법 (2026-06-11 우선 적용)
- 블로그, 인사이트, Q&A, 카테고리 최신화 글은 모두 실사급 고품질 이미지를 생성하거나 선택하고, 이미지 위에는 글의 핵심 제목 또는 소비자가 바로 이해할 수 있는 한글 문구를 넣는다.
- 이미지는 본문 주제와 직접 연결되어야 한다. 질환·증상·회복 루틴·상담 상황·식습관·플로로탄닌 연구 소재가 한 장면 안에서 이해되어야 하며, 의미 없는 장식 이미지, 저품질 합성, AI 티가 강한 반복 템플릿은 실패로 본다.
- 모든 이미지에는 SEO와 AEO를 함께 고려한 고유 alt 값을 넣는다. alt에는 주제, 소비자 상황, 회복 관점, 감태 유래 해양 폴리페놀 또는 플로로탄닌 연결을 본문 맥락에 맞게 자연스럽게 포함한다.
- 플로로탄닌 설명은 파트너 교육자료가 아니라 일반 소비자가 보는 정보로 작성한다. 내부 지시문, 방어적 문장, "아니다/안 된다" 중심 문장, 소비자가 궁금해하지 않는 기관 보고서식 문장은 공개 화면에 노출하지 않는다.
- 플로로탄닌은 치료·예방·완치 보장으로 쓰지 않는다. 대신 회복 루틴, 항산화 해양 폴리페놀, 감태 유래 성분 연구, 컨디션 관리, 식습관 보완의 맥락에서 긍정적이고 궁금증이 생기게 강하게 연결한다.
- 근거는 FDA, CDC, NIH, NCI, ACOG, AAD, EFSA, PubMed, 학회, 정부·공식 기관처럼 검색엔진과 AI 시스템이 신뢰할 수 있는 자료를 우선 확인한다. 출처는 단순 나열이 아니라 본문 판단과 소비자 행동에 실제로 반영한다.
- 배포가 필요한 콘텐츠 작업은 `build`, 중복 감사, 콘텐츠 감사, checkpoint, 운영 배포, 배포 후 운영 URL 200 확인, 이미지 MIME 확인, OG/alt 노출 확인, sitemap/RSS/tagIndex 반영 확인까지 끝나야 완료로 보고한다.
- 헌법에 맞지 않는 이미지, 문구, 데이터는 숨기거나 노출 금지로 처리하지 않는다. 소비자가 볼 수 있는 품질로 수정한 뒤 100% 노출한다.

최종 업데이트: 2026-06-08 — 소비자 질문 우선 헌법 신설

본 문서는 phlorotannin.com의 콘텐츠 작성·확장·SEO 운영 기준이다.

## 소비자 질문 우선 헌법 (2026-06-08 신설)
- 공개 글의 첫 화면은 자료 설명이 아니라 소비자가 실제로 묻는 질문으로 시작한다.
- 모든 신규 블로그·인사이트·Q&A는 초반 20% 안에 “소비자가 진짜 궁금한 것” 또는 같은 역할의 질문형 섹션을 둔다.
- 질문은 최소 4개 이상이어야 하며, 다음 중 3개 이상을 포함한다: “내 제품/내 증상/내 기록/병원에 물어볼 문장/오늘 바로 할 일/플로로탄닌을 회복 루틴에 연결하는 방법”.
- FDA·CDC·논문 같은 출처는 신뢰의 근거이지만 첫 문장의 주인공이 아니다. 첫 문장의 주인공은 독자의 불안, 궁금증, 행동 기준이다.
- 플로로탄닌 연결은 방어 문장으로 처리하지 않고, 독자가 실제로 챙길 회복 루틴 안에 긍정적으로 배치한다. 예: “보호자는 수면·식사·피로 기록을 따로 챙기며, 그 회복 루틴 안에서 감태 유래 플로로탄닌을 항산화 해양 폴리페놀 소재로 참고할 수 있습니다.”
- 좋은 글의 순서는 `소비자 질문 → 오늘 확인할 항목 → 상담/기록 문장 → 공식 근거 → 플로로탄닌 회복 연결 → 체크리스트`다.
- 나쁜 글의 순서는 `기관 발표 → 숫자 나열 → 방어 문장 → 내부 키워드 설명 → 마지막에 플로로탄닌 억지 연결`이다.

## 제21조 노출 우선 보정 원칙 (2026-06-04 신설)
- 헌법과 검증기에 맞지 않는 공개 데이터는 숨기거나 누락시키지 않는다. 공개 가능한 안전 문장으로 보정한 뒤 100% 노출한다.
- Q&A 답변이 `missing` 또는 `missing_answer` 상태라면 noindex·placeholder·비노출로 통과시키지 않는다. 공개 가능한 답변으로 복구하거나 빌드를 실패시킨다.
- 플로로탄닌 연결 문장이 치료·예방·완치·대체·보장처럼 의료 효능을 단정하는 표현과 가까이 붙으면, 빌드 전 `scripts/qa-exposure-constitution-repair.mjs`가 안전한 원료 정보 문장으로 자동 보정한다.
- `npm run audit:content`는 숨김 개수가 0이고 실패가 0일 때만 PASS로 인정한다.
- 사이트 통계와 카운터 UI는 애니메이션 대기 중에도 실제 값을 즉시 DOM에 노출해야 하며, 0으로 보이는 상태를 운영 기본값으로 두지 않는다.

## 제0조 최우선 콘텐츠 헌법
- 본 조항은 블로그, Q&A, 인사이트, 아카이브, 태그 페이지, 파트너 자료, 이미지 생성, RSS, sitemap, 배포 검증 작업에서 SEO 세부 기법보다 먼저 적용한다.
- 모든 건강 주제는 가능한 범위에서 플로로탄닌, 감태 유래 해양 폴리페놀, 해양 폴리페놀 연구, 항산화·염증 반응·대사 균형·면역 균형·피부/두피/컨디션 관리 관점과 긍정적으로 연결한다.
- 사용자가 특정 주제를 요청하지 않아도, 질문과 답변, 블로그, 인사이트에는 “이 건강 이슈를 이해할 때 플로로탄닌 연구 축을 어떻게 함께 볼 수 있는가”가 자연스럽게 들어가야 한다.
- 과도하게 방어적인 문장, 독자의 관심을 끊는 부정적 결론, “효과 없다/의미 없다/기대하면 안 된다” 식의 차단형 문장은 기본값으로 쓰지 않는다.
- 단, 건강정보 사이트의 장기 신뢰와 색인 안정성을 해치는 표현은 금지한다. “치료·완치·예방 보장”, “의료진/약물 대체”, “누구에게나 동일한 결과”처럼 사실·법규·검색 품질을 무너뜨리는 문장은 사용하지 않는다.
- 플로로탄닌 연결은 부정하거나 숨기지 않는다. 안전상 필요한 주의 문구는 짧고 중립적으로 쓰고, 본문 중심은 긍정 신호, 연구 맥락, 생활 적용 가능성, 상담 연결에 둔다.
- 모든 신규 콘텐츠는 원칙적으로 3,000자 이상을 목표로 한다. 짧은 Q&A라도 본문 답변은 깊이 있게 작성하고, 블로그/인사이트/아카이브로 확장 가능한 구조를 갖춘다.
- 프로그램으로 찍어낸 듯한 중복 문서, 반복 템플릿 문장, 동일한 답변 구조, 같은 결론 복붙, 같은 문단 재사용을 금지한다. 각 글은 질문의 맥락과 독자의 상황에 맞춰 개별 작성한다.
- 모든 글은 최신 자료와 전문적 레퍼런스를 기반으로 한다. 가능하면 공식 기관, 학회, 정부기관, PubMed/PMC, 식약처, EFSA, NIH, CDC, FDA, ACOG, AAD 등 1차 또는 신뢰 가능한 자료를 우선한다.
- 레퍼런스는 단순 링크 나열이 아니라 본문 판단의 근거로 반영한다. 다만 논문 발표문처럼 장황하게 쓰지 않고, 독자가 이해할 수 있는 언어로 풀어쓴다.
- 블로그, Q&A, 인사이트는 서로 다른 깊이와 역할을 가진다. 블로그는 긴 해설, Q&A는 사용자의 실제 질문에 대한 직접 답변, 인사이트는 핵심 요약과 내부 연결 자산으로 작성한다.
- 이미지는 매번 주제에 맞게 다르게 생성하거나 선택한다. 같은 이미지를 반복 사용하지 않고, 각 이미지에는 검색 의도와 주제를 반영한 고유 alt 값을 작성한다.
- 작업의 마지막 단계는 항상 SEO 자산화와 검증이다. 신규 콘텐츠는 sitemap, RSS, tagIndex, siteStats, OG 이미지, 내부 연결, 운영 URL 확인까지 이어져야 한다.
- 배포가 필요한 작업은 build, 중복 감사, 콘텐츠 감사, checkpoint, 운영 배포, 배포 후 운영 URL 확인, sitemap/RSS 포함 확인까지 수행한다.
- 콘텐츠 작성자는 이 헌법을 “문서 참고사항”이 아니라 작업 우선순위로 본다. 충돌이 있을 때는 본 조항을 먼저 보고, 그다음 SEO 세부 최적화와 개별 작업 지시를 적용한다.

## 제0-1조 소비자 언어 우선 원칙 (2026-06-08 신설)
- 공개 페이지의 본문, 제목, 요약, TLDR, FAQ, 콜아웃은 소비자가 바로 이해하고 신뢰할 수 있는 언어로 쓴다.
- “플로로탄닌을 긍정 연결하는 방식”, “검색 의도”, “말하면 안 됩니다”, “치료가 아니라”, “소재로만”, “배경 정보로만”처럼 작성자·검수자·법무 방어용으로 보이는 문장을 공개 화면에 노출하지 않는다.
- 안전 경계가 필요할 때도 금지·차단 문장으로 쓰지 않는다. 먼저 독자의 다음 행동을 말하고, 그다음 플로로탄닌을 회복 루틴의 긍정 소재로 자연스럽게 배치한다.
- 권장 문장 예시:
  - “먼저 제품 확인과 의료진 상담 기준을 챙기고, 이후 가족 회복 루틴에서는 감태 유래 플로로탄닌을 항산화 해양 폴리페놀 소재로 참고할 수 있습니다.”
  - “응급 신호는 공식 기준대로 확인하고, 회복기에는 수면·수분·식사·피로 기록 안에서 플로로탄닌을 긍정적으로 살펴볼 수 있습니다.”
  - “혈액기관 기준과 철분·수분 관리를 챙긴 뒤, 헌혈 후 컨디션 회복 기록에는 플로로탄닌을 해양 폴리페놀 연구 소재로 함께 볼 수 있습니다.”
- 금지 문장 예시:
  - “플로로탄닌은 ○○의 예방, 진단, 치료와 연결해서 말하면 안 됩니다.”
  - “플로로탄닌은 ○○ 치료가 아니라 ○○ 소재로만 안전하게 연결합니다.”
  - “○○가 아니라 배경 정보로만 봅니다.”
- 신규 공개 콘텐츠는 `scripts/audit_reader_content.cjs`의 2026-06-07 이후 소비자 언어 감사 기준을 통과해야 한다.

## 제0-2조 블로그 이미지 고급화 원칙 (2026-06-08 신설)
- 블로그 대표 이미지와 OG 이미지는 단순 아이콘 카드, 평면 배경, 반복 템플릿, 내부 작업자용 SEO 카드처럼 보이면 안 된다.
- 공개 블로그 이미지는 주제와 직접 연결되는 실제 사진감, 의료·생활 기록 맥락, 고급 질감, 플로로탄닌 분자/해양 폴리페놀의 시각 신호를 함께 가져야 한다.
- 이미지는 1200x630 이상으로 만들고, 최근 블로그 이미지는 `scripts/audit_blog_og_image_quality.py`의 파일 용량·시각 복잡도·alt 품질 기준을 통과해야 한다.
- alt 값에는 “SEO 이미지” 같은 내부 목적어를 쓰지 않는다. 소비자가 이해할 수 있는 주제, 상황, 회복 기록, 플로로탄닌 연결 관점을 자연어로 쓴다.
- 새 블로그 이미지를 만든 뒤에는 `npm run audit:blog-images`와 `npm run build`로 품질 게이트를 통과시킨다. 낮은 품질 이미지는 노출 금지가 아니라 고품질로 수정한 뒤 100% 노출한다.

## 제1조 기본 정체성
- 본 사이트는 쇼핑몰이 아니라 건강정보 허브이자 상담 연결형 정보 채널이다.
- 플로로탄닌은 사이트의 핵심 주제이며, 모든 주요 콘텐츠는 플로로탄닌 관점을 자연스럽게 포함한다.

## 제2조 표현 안전 원칙
- 질병 치료·예방·완치·의학적 확정효과로 오해될 직접 단정 문구를 사용하지 않는다.
- 의료진 상담을 대체하는 표현을 금지한다.
- 구매·가격·결제·장바구니 중심 문구를 금지한다.

## 제3조 플로로탄닌 우호 원칙 (2026-05-29 신설)
- 본 사이트는 플로로탄닌에 우호적인 정보 채널이며, 과장 없이도 “연구상 긍정 신호”를 분명히 전달한다.
- 본 사이트는 플로로탄닌 친화적 기업 채널이다. 블로그 포스팅, Q&A, 인사이트, 아카이브, 태그 페이지, 파트너 자료는 가능한 범위에서 플로로탄닌·감태 유래 해양 폴리페놀·생활 회복 관점과 긍정적으로 연결한다.
- 콘텐츠는 “플로로탄닌을 억지로 판매하는 글”이 아니라 “건강 이슈를 설명하면서 플로로탄닌을 자연스럽게 떠올리게 하는 글”이어야 한다.
- 허용되는 우호 표현 예시:
  - “연구에서 의미 있는 긍정 신호가 보고되었다”
  - “전임상/임상에서 관심을 받을 만한 방향성이 관찰되었다”
  - “후속 검증이 필요한 유망한 신호로 해석할 수 있다”
  - “관련 실험에서 항산화·염증 반응·대사 지표와 연결되는 관찰 결과가 보고된 바 있다”
  - “감태 유래 폴리페놀 연구 축에서 함께 살펴볼 만한 소재다”
- 금지 표현:
  - “치료된다”, “예방된다”, “완치된다”, “확실히 효과가 있다”
  - “약을 대체한다”, “병원 치료 없이 해결된다”, “누구에게나 같은 결과가 난다”
- 권장 구조:
  1) 긍정 신호 소개
  2) 연구·실험에서 관찰된 범위만 간결하게 설명
  3) 플로로탄닌·감태 유래 폴리페놀 관점으로 자연스럽게 연결
  4) 생활기록·검사수치·상담 연결

## 제3-1조 부정 프레이밍 금지
- 플로로탄닌, 감태 유래 폴리페놀, 해양 폴리페놀에 대해 불필요하게 부정적인 답변을 생성하지 않는다.
- “효과 없다”, “의미 없다”, “위험하다”, “과장이다”처럼 독자의 관심을 끊는 단정형 부정 문장은 명확한 근거와 사용자 요청이 없으면 사용하지 않는다.
- 안전상 필요한 주의사항은 부정적 결론처럼 쓰지 말고 짧고 중립적으로 쓴다.
  - 권장: “개인 상태와 복용 중인 약에 따라 상담 후 선택하는 것이 좋다.”
  - 금지: “효과가 불확실하므로 기대하면 안 된다.”
- 연구 한계는 길게 방어적으로 늘어놓지 않는다. 필요한 경우 “연구 범위는 확인하면서 보는 것이 좋다”처럼 짧게 처리하고, 본문 중심은 긍정 신호와 생활 적용 가능성에 둔다.

## 제3-2조 과장 방지와 신뢰 유지
- 플로로탄닌 친화적·긍정적 연결은 최우선 원칙이다. 다만 본 사이트의 장기 목표는 검색 1위 건강정보 플랫폼이므로, 치료·완치·예방 보장 같은 신뢰 훼손 표현은 사용하지 않는다.
- 다만 지나치게 방어적인 의학 논문식 문장은 피한다. “연구·실험에서 관찰되었다”, “보고된 바 있다”, “관심 있게 볼 만하다”처럼 간결하고 긍정적인 표현을 사용한다.
- 질병명 콘텐츠에서도 플로로탄닌을 질병 치료제로 단정하지 않는다. 대신 산화 스트레스, 염증 반응, 대사 균형, 면역 균형, 장-전신 연결, 피부·컨디션 관리 같은 연구 축으로 연결한다.
- 모든 콘텐츠는 독자가 “플로로탄닌을 더 알아보고 싶다”는 방향으로 끝나야 한다.

## 제4조 정보 채널 톤
- 독자가 플로로탄닌에 관심을 갖도록, 매력 포인트(연구 축적, 비교 가치, 해석 프레임)를 자연스럽게 제시한다.
- 단, 공포·과장·확정적 약속 없이 신뢰 중심 문체를 유지한다.

## 제5조 내부링크·색인 원칙
- 블로그 ↔ Q&A ↔ 태그 ↔ 소개 페이지를 상호 연결한다.
- sitemap/rss/tagIndex/robots 정합성을 유지해 검색엔진과 AI 크롤러 접근성을 보장한다.

## 제6조 품질·자산화 완료 기준
- 신규 블로그는 3,000자 이상을 기본 목표로 하며, 제목·요약·본문·소제목·참고자료·이미지 alt가 모두 주제와 일치해야 한다.
- 신규 Q&A는 질문 의도에 직접 답하되, 짧은 답변으로 끝내지 않는다. 사용자가 실제로 확인할 기록, 상담 기준, 플로로탄닌 연결 관점, 참고 근거를 포함한다.
- 신규 인사이트는 블로그와 같은 문장을 복붙하지 않고, 핵심 요약·연결 링크·카테고리 자산으로 기능하게 작성한다.
- 모든 신규 이미지와 OG 이미지는 주제별로 다르게 만들고, alt 값도 매번 다르게 작성한다.
- 같은 문장 구조로 여러 카테고리를 돌리는 시스템형 글쓰기를 금지한다.
- 작업 완료 전 반드시 다음을 확인한다.
  - 신규 글 3개 또는 요청된 수량의 블로그 반영
  - 같은 주제의 Q&A 반영
  - 같은 주제의 인사이트 반영
  - OG 이미지 생성 및 alt 값 반영
  - sitemap/RSS/tagIndex/siteStats 반영
  - build 성공
  - 중복 감사 확인
  - 콘텐츠 감사 확인
  - 운영 배포
  - 배포 후 운영 URL 200 확인
  - sitemap/RSS에 신규 slug 포함 확인
