## 4. 제출 절차 권장 순서

1. **사이트맵 등록**: Search Console → Sitemaps → `sitemap.xml` 입력 → 제출
2. **URL 검사로 핵심 페이지 우선 색인**: 위 섹션 2-1(10건) → 2-3(신규 30건) 순서로 "색인 요청"
3. **24~48시간 후 커버리지 보고서 확인**: 색인됨 / 발견됨 / 제외됨 수치 모니터링
4. **실적 보고서**: 2주 후 검색 노출/클릭 키워드 확인 → 빈약한 페이지 보강

> 💡 **Tip**: Search Console "URL 검사"의 색인 요청은 하루 10건 정도가 안정적 한도입니다. 신규 30편 → 3일에 걸쳐 분산 요청 권장.
